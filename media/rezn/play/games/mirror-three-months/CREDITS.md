# 거울 속의 석 달 에셋

표지 `cover.webp`는 사용자가 제공한 `cover-v2-no-korean-1600x1200.png` 원본(1600×1200, 4:3)이다. 목록·작품 소개·구매·보관함에 공통으로 사용한다.

그 외 이미지는 2026-10-16 이 작품을 위해 OpenAI 이미지 생성 도구로 제작한 원본 수채화 일러스트다. 특정 영화·뮤지컬의 인물 디자인을 사용하지 않았다. 인물·사건 원안은 제공된 제작 문서, 문학적 바탕은 R. L. Stevenson의 1886년 소설이다.

- `bg-street.webp`: 그레이 레인 거리·지도·표지 배경.
- `bg-mirror.webp`: 밤 일기·거울 장면 배경.
- `portraits.webp`: 투명 배경 4열×3행. 지킬/하이드/메릴다/스바로우, 이사벨/어터슨/그레이스/마샤, 릴리/한나/버트/그레이브스 순서.
- `locations.webp`: 3열×3행. 침실/현관과 가게/병원, 선술집/어터슨 사무소/그레이스 집, 하숙집/광장/법정 순서.

지킬과 하이드는 같은 얼굴을 공유한다. 현재 인물별 기본 초상 12종을 사용하며 개별 표정 50종은 제작하지 않았다. 표정은 대사와 화면 표현으로 보조한다. 밤·회상 필터는 CSS, 회중시계와 종이 넘김 효과음은 Web Audio로 만든 짧은 합성음이다. 외부 음원·음성 녹음·배경음악은 포함하지 않는다. UI 장식과 지도 표시는 HTML/CSS로 그린다.
